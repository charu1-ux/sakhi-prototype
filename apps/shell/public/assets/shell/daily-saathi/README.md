# Daily Saathi home — avatar / icon assets

Drop these three image files into this folder (exact filenames). Until they are
present, the Daily Saathi home falls back to JDS SVG icons automatically.

| File               | Where it shows                                                       | Suggested image                                            |
| ------------------ | -------------------------------------------------------------------- | ---------------------------------------------------------- |
| `daily-saathi.png` | Circle beside the "Daily Saathi" title in the landing header         | Daily Saathi brand/mascot avatar                           |
| `dil-ki-baat.png`  | Avatar circle on the दिल की बात (Talk to me) CTA + companion lead-in | Warm companion avatar (e.g. the illustrated girl with mug) |
| `kaam-ki-baat.png` | Avatar circle on the काम की बात CTA + Kaam Ki Baat chat avatar       | Assistant avatar (e.g. the professional figure)            |
| `namaste.png`      | Circle beside "Namaste, Priyam" greeting                             | Namaste 🙏 hands icon (transparent background preferred)   |

Notes:

- Square images crop cleanly (rendered in a circle via `object-cover`).
- ~256–512px is plenty for these small circles.
- `namaste.png` looks best with a transparent background.
