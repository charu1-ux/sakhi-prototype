# Personal Companion assets

Drop the Dil Ki Baat persona image here as:

    avatar.png

A square image works best (it's cropped to a circle, focused near the top so the
face is framed). It appears in the chat header, message bubbles, typing
indicator, profile sheet, and call screen. If `avatar.png` is missing, the UI
falls back to the purple heart-glyph avatar automatically.
